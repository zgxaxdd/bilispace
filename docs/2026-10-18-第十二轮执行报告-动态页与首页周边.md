## 2. `feature/dynamic`：dp **77 → 11**，`MaterialTheme.shapes.*` **12 → 0**

改前的核心问题是**形状来源失控**：同一张动态卡里，点赞/转发/评论/分享 chip 用 `shapes.extraLarge`(28)、转发引用块用 `medium`(12)、角标用 `extraSmall`、媒体封面/九宫格用 `small` —— **5 套互不相干的半径**，而且全部随 `CornerStyle` 漂移。

改后是**三级 token 阶梯**：
- 动态卡 `BiliRadius.card`(20) —— 与全站卡片同一档；
- 统计 chip / 转发引用块 / 评论预览 `groupedList`(16)；
- 角标 / 媒体封面 / 九宫格 `badge`(8)。

所有 shape 都提成**文件级 `private val`**（不在调用点内联 `RoundedCornerShape(...)`，也不在 composable 体内建 —— 那两条棘轮上一轮刚抓过人）。
间距 66 处 token 化（数值全部不变）。保留 11 处业务尺寸（头像 42/44、图标 15、媒体宽 132/140、缩略图 88、`2.dp` 角标内边距 —— 最小 token 是 4dp，硬套会撑变形）。

**数据/交互零改动**：`items(key=…)`、`LaunchedEffect`、`LoadMoreGrowthGuard`、滚动跟随、既有动画（点赞 tint + 图标弹跳）全部原样。
