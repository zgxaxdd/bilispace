## 4. 为什么配色只交付工厂、不接线（决策记录）

三条路都评估过：A 旁路式接线（需新增 `ThemeConfig.seedPaletteStyle` + 非 Standard 跳过 `applyPaletteStyle`）、B 全面替换（改默认种子观感）、C 只交付工厂。
选 C，因为：
1. 用户当前跑 **iOS 档**，`UiStyle.IOS -> iOSColorScheme(...)` 根本不进 seed 分支 ⇒ A/B/C 对他的观感都无影响；
2. A 新增的配置字段**没有任何 UI 能设置** ⇒ 造出"生产永远传 Standard"的假接线；
3. 本仓在基底之上有 3 层后处理，A 必须为其开旁路分支，应和"设置页入口 + 默认色 A/B 决策"同批做；
4. **没有真机复验不改用户可见默认值**。
