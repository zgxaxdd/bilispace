## 2. 结论

1. **本区间没有任何"可直接搬运的完整实现"**——与 SX-11（v0.2.5→v0.2.7）的结论一致。
   根本原因未变：**bbspace 是重写实现，不是上游的分支**（模块划分、导航栈、弹幕栈、播放器浮层全都不同源）。
2. 本区间的重量级内容（BAS 原生弹幕 +3852 行、BlueSnowMaid 品牌动效 + 新模块、平板分栏导航、TV 端）
   **全部落在 bbspace 没有 substrate 的位置**，属 SOP §3.2 的 C 级判据（"上游解决的是本仓没有的问题"）。
3. 上游这一轮**没有改动 feed 取流路径、评论取流路径、登录/签名基础设施**——
   即 bbspace 与上游差异最大的那几块（MERGED 双源、WbiKeyProvider、评论 read-plan）本区间**零变化**，无需对齐。

## 3. 与上游的差异点（供执行报告引用，逐条）

1. **弹幕**：上游把弹幕做成 `danmaku-engine` 模块（BAS 脚本解析 + Canvas 覆盖层 + 分段窗口策略）；
   bbspace 是 `core/danmaku` + `infra/player/danmaku` 的独立实现。**不构成对齐项**。
2. **开屏/品牌动效**：上游 `brand-motion` 模块 + `artwork/brand-motion` 52 个资产 + `StartupAnimationStyle`；
   bbspace 无开屏动效体系，唯一 `splash` 命中是 feed 接口参数。**不构成对齐项**。
3. **设置分栏导航**：上游 navigation3 + `SettingsAdaptiveSceneHost`（且这一轮里被 revert 又重新修补三次）；
   bbspace 用 Compose Navigation `AppNavHost.kt`。**不构成对齐项**。
4. **竖屏互动栏视觉**：上游这一轮把底衬从黑→白→**整个删掉**，最终是"纯白图标无底衬"；
   bbspace 保持深色底衬 + 0.88 缩放（SX-02 决策）。**方向相反，是有意分歧**。
5. **点赞取消语义**：上游用 `NonCancellable` 保证退出详情页也在途送达；
   bbspace 显式选择"取消向上传播、不伪装成失败"（`VideoViewModel.kt:1374-1379`）。
   两者不矛盾但**落点不同**，若要吸收只能改造（见 §1 #16）。**未落地**。
6. **后台播放**：上游竖屏 pager 原先会在 `ON_STOP` 暂停，这一轮补了豁免；
   bbspace 的 `PortraitSwipePager.kt` 本就没有该暂停逻辑。**无对象**。
7. **SponsorBlock**：上游补了投票路径（`-1`→`0` 是**真 bug 修复**）与请求头替换；
   bbspace 是只读实现（只取片段、不投票）⇒ **该 bug 在 bbspace 不存在**。
8. **TV 端**：上游 `app-tv` 28 文件；bbspace 无 TV 模块。**全部 C**。
