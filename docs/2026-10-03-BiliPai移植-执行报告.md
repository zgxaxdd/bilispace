### PT-03 续播语义对齐

  2. **MERGED 的 app 半边直接复用 `fetchMobile`**，不照搬上游 `fetchMergedMobileFeed` 的 `android_hd` 专用参数集（那是上游 app 端点的另一套身份头策略，bbspace 无对应物）。`S-A` §4.5 也只要求"照抄交错语义"。
  3. **`fresh_type` 取值按方案 §4.4**：首屏/翻页 3、下拉刷新 4（上游 solo WEB 恒 3、MERGED-WEB 恒 4；本仓按 `pull` 区分）。
  4. 第一版**不剥 Cookie**（上游 `HomeFeedAnonymizerPlugin` 是反回流方向，与本方案目标相反）。
  5. 无 `idx` 的 web 卡片 → `FeedItem.idx = 0`，其 `actionKey = "av|<aid>|0"` 仍全局唯一（不会触发 LazyStaggeredGrid 重复 key 崩溃）。
- 验收：**V1~V10 全绿**（`FeedApiTypeTest` 4、`WebFeedMapperTest` 10、`FeedMergePolicyTest` 7、`FeedCursorPolicyTest` 5、`FeedSourceDispatchGuardTest` 9、`FeedApiTypeSettingsGuardTest` 4 = 39 条）；7 处探针：
  `FEED_ENDPOINT` 字面量 / `dislikeContext` 非空 / 设置页限制文案 / `fromValue` 兜底改 WEB / `fetchMobile` 的 `hdFeed` 实参 / 旧入口改成分派 / 设置文案（受控重测）—— 均 FAILED，还原后 sha256 一致。
