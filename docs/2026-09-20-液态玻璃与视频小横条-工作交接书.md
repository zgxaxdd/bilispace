### 1.2 三态机（`LinkedDockPhase`）

```
enum class LinkedDockPhase { Expanded, Playback, Search }
```

| 态 | 含义 | 进入条件（策略函数） |
|---|---|---|
| `Expanded` | 完整导航底栏（单行） | 上滑；无播放内容时（`resolveLinkedDockRestingPhase`）；`Search` 退出且无播放 |
| `Playback` | **小横条合并进底栏**（导航收敛 + 横条内嵌） | **下滑累积 ≥ 24dp 且存在播放内容**（`hasAudio`）；`Search` 退出且存在播放 |
| `Search` | 底栏内展开搜索框 | 点击搜索（任务 2 相关，BBSpace 暂未接） |

### 1.3 滚动触发策略（关键，勿用定时器/逐帧耦合）

源码 `LinkedBottomDock.kt:98-117`：

```kotlin
val threshold = with(LocalDensity.current) { 24.dp.toPx() }
LaunchedEffect(currentItem, hasAudio, scroll, threshold) {
    if (currentItem != BottomNavItem.HOME) return@LaunchedEffect   // 仅首页生效
    var previous = scroll.floatValue
    var accumulated = 0f
    snapshotFlow { scroll.floatValue to scrolling }.collect { (offset, active) ->
        val delta = offset - previous
        previous = offset
        if (!active || phase == LinkedDockPhase.Search) {
            accumulated = 0f
        } else {
            accumulated = accumulateDockScroll(accumulated, delta)
            if ((offset <= 0f && delta < 0f) || accumulated <= -threshold) {
                updatePhase(LinkedDockPhase.Expanded)      // 上滑 / 回到顶部 → 展开
                accumulated = 0f
            } else if (hasAudio && accumulated >= threshold) {
                updatePhase(LinkedDockPhase.Playback)      // 下滑累积到阈值 → 合并
                accumulated = 0f
            }
        }
    }
}
```

- `accumulateDockScroll(previous, delta)`：**方向反转即重置**（`if (previous * delta < 0f) delta else previous + delta`），防抖动闪烁；
- 阈值 **24dp**（不是像素满程比例）；
- 只在**首页 Tab** 生效；
- 滚动停止（`active=false`）时累积清零。

### 1.4 动画规格

| 项 | 规格（源码 `:130-148`） |
|---|---|
| 合并进度 `merge` | `updateTransition(phase).animateFloat(iosMorphTween(280ms)) { if (Expanded) 0f else 1f }` |
| 搜索进度 `search` | `iosMorphTween(240ms)` |
| 无障碍 | `rememberSystemReduceMotion()` 为真时 `snap()`（无过渡） |
| 导航内容淡出 | `alpha = (1f - merge*3f).coerceIn(0f,1f)`（合并初期快速淡出） |
| 播放内容淡入 | `alpha = (merge*2f).coerceIn(0f,1f)` |
| 导航内容移除 | `if (merge.value < 0.999f) navigationContent()`（完全合并后不再组合） |
| 合并态点击 | 整个底栏 `clickable { expand() }` → 回到 `Expanded` |
| 合并态指针 | `phase != Expanded` 时 `PointerEventPass.Initial` 消费全部指针事件 |

> **要点**：合并是**阈值触发的 280ms tween 动画**，不是随手指逐帧插值——这是「丝滑」的来源。

### 1.5 几何公式（`resolveLinkedDockGeometry`，小横条在行间移动的核心）

> 源码注释原文：*"A single audio child is measured and moved between rows. Playback and artwork stay mounted."* —— **同一个横条子节点在行间被移动**，不是两个组件交叉淡入。

```kotlin
val top = ((if (hasAudio) barHeight + verticalGap else 0) * (1f - merge)).roundToInt()   // 横条行高度
val compactAudioWidth = (width - button - searchWidth - playbackGap * (if (searchEnabled) 2 else 1)).coerceAtLeast(0)
audioWidth = (width + (compactAudioWidth - width) * merge).roundToInt()                  // 满宽 → 紧凑宽
audioX     = ((button + playbackGap) * merge).roundToInt()                               // 左移到首个导航项之后
audioY     = (top * merge).roundToInt()                                                  // 下移到导航行内
height     = top + barHeight                                                             // 底栏总高随 merge 收缩
```

- `merge=0`（Expanded）：横条独占一行，**满宽**，位于导航行**上方**；
- `merge=1`（Playback）：横条**收窄并左移**到「首个导航项之后」，与导航同行；
- 搜索宽度 `searchWidth` 按 `search` 进度在 `button` 与最大可用宽之间插值。

## 三、根因档案（勿重蹈）

### 3.1 液态档整个表面渲染为空
- **现象**：选「液态」后 Dock / 顶栏 / 胶囊全部不可见（内容消失，非变透明）。
- **根因**：在 `hazeEffect` 外层再包一层 RuntimeShader `graphicsLayer`（旧 `liquidGlassSurfaceV2` 路线）。
- **结论**：**永远不要**在 haze / miuix 玻璃节点外再包 RenderEffect 层；官方折射在背板绘制**内部**（`miuixLens`）。旧实现保留在 `LiquidGlassShaderV2.kt`，已标 `@Deprecated`。

### 3.2 滚动衔接处残影 / 发黑（三重根因，缺一不可修）
1. **录制不随子内容滚动重录**：`hazeSource` / miuix `LayerBackdrop` 的录制节点只在自身重绘时重录；列表滚动只重绘列表节点 → 玻璃采样到上一帧。
   → 修复：`GlassRefresher`（NestedScroll 逐帧 tick）+ 源节点外层 `drawWithContent { refresher.frame; drawContent() }`。
2. **消费端光栅冻结**：玻璃节点被移出屏幕期间（Dock 滚动隐藏）停止重采样，滑回时复用旧光栅。
   → 修复：消费端挂 `Modifier.glassFrameRefresh(refresher)`；**且播放会话激活期间固定 Dock**（`rememberTopLevelNavVisibilityController(fixBottomBar || capsuleState.active)`），避免自动隐藏与联动动画抢戏。
3. **文字区透明缺底色**（最隐蔽）：双列卡片文字区无底色，页面 `background` 画在录制链**外** → 背板里文字区是空像素 → 玻璃采样后渲染成**黑色**（封面不透明所以正常，表现为“图片正常、简介发黑”）。
   → 修复：`background` 必须画在录制链**内**（`.then(backdropSource.modifier).then(hazeSource).background(...)`）。

### 3.3 源码定位教训
- 本轮曾一度把「可拖拽悬浮小窗 + 贴边收起」那类实现当作「小横条」——**那是悬浮窗，不是联动底栏**，已弃用。
- **正确判别依据**：真实现必含 `LinkedDockPhase{Expanded,Playback,Search}` 三态、`nowPlayingContent` 内容槽位、`accumulateDockScroll` 阈值策略、`resolveLinkedDockGeometry` 的横条行间移动几何（见第一节）。找不到这四样就不是本任务的目标实现。
