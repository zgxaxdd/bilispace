## 2. 三条关键观察

**① 墨迹带与三档文字在三种几何下**一个数都没变**（0.8800 / 16.56 / 14.15 / 6.74）。
原因：控件行那 34dp **恒在平坦段内**。⇒ **动平台起点不会动文字**，这条永远成立。

**② 唯一会动的是轨道带**：3.12 →（提亮后）3.75/3.33。
⇒ **轨道提亮 0.42→0.50 是纯增益**：余量从 **4% 放到 25%**，且**不触碰任何文字断言**。

**③ 核查员那条"0.50 ⇒ 3.49"我更正**：那是按 0.72 平台的几何算的。
**当前树（起点 0.50）下轨道提亮到 0.50 是 3.75**（不是 3.49，也不是他说的 3.88——
他用中心口径，我用带 min 口径，**带 min 更保守，以守卫实跑为准**）。
