## 关键决策

- **替换而非叠加**：旧黑幕读作"播放器的黑糊下来"，与"光洒下来"目标相反。真机对照后整层删除。
- **光源 = 封面代表色**（`VideoCardCoverColorStore`，BiliPai 上游同款缓存/防重路径）：向白 lerp
  （深色底 0.65 / 浅色底 0.50）成"发光的淡彩"；无取色时退纯白（屏幕本光）。取色请求 URL 与
  `CoverSettleBackdrop` 对齐 → 命中同一条 Coil 内存缓存，零额外下载。
- **峰值亮度分档**：深 0.22 / 浅 0.16（上游卡片光晕 0.48/0.38 的分档方向，光程 56dp 按比例收敛）；
  消散曲线仍是 `ProgressiveFadeDefaults` 非线性 5 档（马赫带守卫，交接书 §6.1）。
- **渐变高度 40dp→56dp**（`BiliSpacing.xxxl * 1.75f`）：光要"洒"开，40dp 只够"糊"。
- **上游渐进模糊档（`biliPaiProgressiveTopBlur`）仍未移植**：需要 miuix
  `0.9.4-5157b503-SNAPSHOT`（bbspace 锁 0.9.4-rc01 release，无 `progressiveTextureBlur`）。
  属依赖升级级改动，本轮不做，挂账 §5.1。
