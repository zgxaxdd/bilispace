## 关键改动（均在 `VideoScreen.kt`）

### 问题 1 —— 描边从「底边直线」改为「整圈圆角 rim light」（`playerSeamStroke` 重写）

- `drawRoundRect(brush, topLeft = Offset.Zero, size = Size(w, seamY), cornerRadius = CornerRadius(r, r),
  style = Stroke(width, join = StrokeJoin.Round))`，r = `BiliRadius.playerCompact`（= card = 20dp），
  与 `.clip(CompactPlayerShape)` 同构，圆角处不再断线。
- 亮度沿**垂直渐变**走线：底边全亮（`SEAM_STROKE_PEAK` = 0.90）→ 弧起点 ≈0.42·峰值（y = seamY−r）→
  弧中段 ≈0.75·峰值（y = seamY−0.5r）→ 圆角上方完全透明；渐变起点 = `seamY − 1.6r`
  （`SEAM_STROKE_RISE` = 1.6f），描边两角处仍是一条连续的渐弱走线。
- **挂载点移到 `.clip(CompactPlayerShape)` 之前**：描边画在裁剪轮廓之外、压在接缝两侧
  （Stroke 中心线在边界上，内外各 0.6dp）。
- **圆角缺口垫底色**：drawContent 之前先画 `drawRect(backingColor, topLeft = Offset(0, seamY−r),
  size = Size(w, r))`（backingColor = `MaterialTheme.colorScheme.background`）——浅色主题下把
  clip 圆角外露出的两只"黑耳朵"（外层黑底）垫平；圆角内随即被 drawContent 的黑底/画面盖住。
- 描边颜色分档不变：深色内容底 → `Color.White`；浅色内容底 → `SeamStrokeGray`（iOS systemGray）。
- brush 在 `drawWithCache` cache 块按当前尺寸构建：静止态零分配；形变期 size 逐帧变化会逐帧重建
  （几个 Pair 的小分配，动画结束即停）。

### 问题 2 —— SrcOver 色浆 → 双层 Screen 加亮（新增 `seamLightSpill`，替换接缝处 topSolidProgressiveFade）

廉价感的主因判定：`topSolidProgressiveFade` 是 SrcOver 色浆，把滚动到顶的文字**糊上一层灰**。
本轮改为两层 `BlendMode.Screen`（只提亮内容，"光洒下来"而不是"雾罩上"）：

| 层 | 高度 | 峰值（深/浅） | 衰减 | 颜色 |
|---|---|---|---|---|
| halo（白色开花） | `SEAM_HALO_DP` = 18f × density | 0.30 / 0.18 | 1.0→0.42→0.12→0（快速） | 纯白 |
| spill（封面淡彩） | `BiliSpacing.xxxl * 2f` = 64dp | 0.14 / **0.20**（浅底反而更高：Screen 在近白底上天然收敛，需更高峰值才读得出"有光"） | 1.0→0.58→0.26→0.09→0（指数式，Telegram 非线性同思路，马赫带守卫） | `lerp(White, coverTint, 0.30/0.40)` —— 主体中性白，封面代表色只做低比例"语气" |

- coverTint 管线不变：`VideoCardCoverColorStore.requestExtraction`（cacheKey/url = `coverBackdropUrl ?: detail.cover`，
  与 CoverSettleBackdrop 同 URL 共享 Coil 缓存）。
- **接缝处不再用 `topSolidProgressiveFade`**（VideoScreen 里该 import 已移除；组件本身保留，AppNavHost 仍在用）。
- `seamLightSpill` 用 `drawWithCache` 缓存 brush；内容区挂载处 `remember` 住 modifier（色值/峰值不变跨重组复用）。
- 内容区 Box 自带 `graphicsLayer`（形变淡出）→ Screen 混合闭合在该 layer 内，只提亮详情内容。
