## 0. 方法与两个踩坑（先说清楚，避免误读结论）

### 0.1 ⚠️ `monkey` 会启动 LeakCanary，不是本 App
调试包内置 LeakCanary，它同样注册了 `LAUNCHER` category ⇒ `adb shell monkey -p <debug> -c android.intent.category.LAUNCHER 1`
**可能启动 `leakcanary.internal.activity.LeakLauncherActivity`**。本轮前两次手势验证全部无效，
正是因为它把输入吃在了 LeakCanary 界面上（表现：任何手势都"没反应"，而日志里连给 App 打点都没有）。
**一律用显式 Activity 启动**：
```bash
adb shell am start -n com.naaammme.bbspace.debug/com.naaammme.bbspace.MainActivity
```

### 0.2 详情页下拉进会话有 **50% 位移阈值**
`pullDownToFullscreen` 的 progress = 手指位移 / (windowBottom − zoneTop)，**释放时 ≥0.5 才提交**。
本机该视频 `zoneTop=856.5px`、span≈1944px ⇒ 需要拖 **>972px**。
`adb shell input swipe 636 1700 636 2790 400`（1090px）可用；
从 y=2000 起拖只有 790px（0.41）**不会**进会话 —— 这正是本轮早期"进不去"的原因之一（另一个是 0.1）。

### 0.3 取证方式
- 静态观感 → `screencap` + 人工看图；
- **动效** → `adb shell "input …; screencap f1; screencap f2; …"`（**同一条 shell 内连拍**，
  省掉每次 adb 往返 ~200ms）→ 相邻帧对比，能拍到"中途帧"就证明是**连续动画**而不是瞬变；
- 帧率 → `dumpsys gfxinfo`（保留原始输出文件）；
- 行为 → `logcat` 里的 `PortraitSwipe:` / `FeedRepository:` 结构化日志。

**同一台机、同一操作脚本、同一会话形态**（竖屏刷视频会话里打开评论面板、手指脚本化上下滑），

**判定**：改造后 **五项指标的中位数全部不劣于基线**（且四项延迟分位各降 1ms）。

## 3. ⚠️ 缺陷：竖屏互动栏的「点赞」点了看不到任何反馈（根因未定位）

### 复现
1. 进竖屏刷视频会话（简介页下拉）；2. 点右侧互动栏第 2 颗（点赞，计数 `20`）；3. 观察。

### 观察（多次重复）
- 点赞按钮 **图标仍为描边、计数仍为 20**（`uiautomator` 前后同值；`31_rail_before.png` vs `32_rail_after.png` 裁剪对比一致）；
- **同一栏的其它三颗都正常**：评论（`cy≈1474`，打开评论面板 ✓）、收藏（`cy≈1758`，打开收藏夹弹窗 ✓）、分享（`cy≈2042`，打开分享面板 ✓）⇒ 热区、坐标、可点性都没问题；
- **详情页**同一个视频的点赞按钮**正常**：数字 `20 → 21`，且 `content-desc` 为 `点赞`；
- 竖屏会话里**未赞态确实渲染为描边图标**（`Icons.Outlined.ThumbUp`）⇒ SX-09 的视觉改动本身生效。

### 为什么不写"通过"，也不写"失败"
有一组**自相矛盾**的信号，所以按铁律「不许猜」不下定论：
- 先ruption：详情页点赞到 21 → 进会话点互动栏点赞 → 返回详情页显示 **20**（与"该点击发出了取消赞"一致）；
- 随后一次：详情页 20（未赞）→ 进会话点互动栏点赞 → 返回详情页仍 **20**（与"该点击根本没发出"一致）。

⇒ 能确定的只有"**互动栏点赞在本机看不到任何反馈**"；**根因未定位**。
（已排除：热区/坐标错位、可点性、`loggedIn()`——详情页同一 `toggleLike()` 能成功。）

### 建议的下一步诊断（一次构建即可）
`withInteraction` 有两条**静默**返回路径：`interactionTargetOf() ?: return`（无提示）与
`if (_interaction.value.busy)`（提示"操作处理中"，但会话内可能不显示）。建议在会话里临时打点：
① `onToggleLike` 是否被调用；② `interactionTargetOf()` 的取值；③ `_interaction.value.busy` 的取值；
④ `actionRepository.setLike` 的 return 与异常。已登记 **BACKLOG `VK-01`**。

### 账号副作用
**无净变化**：测试结束时该视频回到 **未赞 / 20**（与开始时一致）。全程只在**调试包**上做写操作；
稳定包只做了只读走查。
