## A. 优先级最高的五项（两分钟能试完）

| # | 怎么试 | 看到什么算对 | 不对时的旋钮 |
|---|---|---|---|
| A1 | 首页底栏**按住左右拖**，再松开；另试**点**每个 Tab | 指示器跟手（略滞后、有阻尼）；拖动中横向拉长；松手吸附到最近一档并切页；点 Tab 时弹簧滑动；指示器与图标**同心**（不偏左偏右） | `DampedDragAnimation.followOffset`（跟手量）/ Dock 里的 `0.16f`（拉伸）/ `LiquidIndicatorMotion.positionSpec()`（速度） |
| A2 | 设置页任意开关（如「深色模式」） | 轨道形变 + 滑块弹簧（miuix）；关态灰、开态主色；禁用态整件变灰 | `AppMiuixSwitch` 的颜色映射（`roles.accent` / `cardElevated`） |
| A3 | 首页/动态/搜索顶部**分段 Tab** | 选中块在轨道内滑动（miuix TabRow 内部 spring），高度 32dp，与旧观感接近 | 若明显不协调 ⇒ 回退 `FilledTabRow` iOS 分支到旧实现（1 处，git 有记录） |
| A4 | 打开任意图片预览，**双击**图片 | 放大到 2.5x，且**手指点的那一点不动**；再双击回到 1x 且图回正中；单击（等约 300ms）关闭预览 | `PreviewZoomPolicy.DOUBLE_TAP_SCALE`（2.5）/ 锚点公式已单测钉死；若"点的地方跑了"⇒ 报我，我查坐标系 |
| A5 | 设置 → 外观设置 → 颜色 →「色彩风格」 | 弹出 22 档列表（底部弹层带拖拽把手）；选非 Standard 后整体配色变化；选 Standard 回到原配色 | 若某档配色难看/刺眼 ⇒ 报档名；工厂参数在 `SeedColorSchemeFactory`，但**默认 Standard 必须保持不变** |

## C. 取数（有这些我才能把性能从"猜"变成"算"）

```bash
adb logcat -s FrameDiag     # 每 10s：fps / jank% / p95 / worst / GC 增量
adb logcat -s MemoryDiag    # trim 时：heap / 图片缓存水位 / 线程数 / GC 累计
adb logcat -s StallDiag     # 播放卡住时：缓冲剩余 / 槽位 / 并行 / 路由 / 最后错误
```

建议场景：① 首页快速滑动 10 秒；② 进视频详情再返回 3 次；③ 长视频播放 3 分钟；④ 切后台/回前台一次。
把日志发我，我按读数定向优化，而不是继续在结构层面推演。

## D. 已知未做（不是 bug，是本轮明确不做的）

- **CDN 属地选线**（设置 → 音视频设置底部）默认全关；开启后改的是候选线路顺序，签名 URL 换 host 在真机上是否 403 **未知**。
- 通知去重/漏报/误清只有**策略层**，本仓没有消息通知宿主（Service/Worker/Notifier/DataStore），所以**没有任何通知行为变化**。
- 图片预览**拖动惯性**未做（`transformable` 不提供手势结束速度，需换手势层，风险高于收益）。
- `glassStrengthCap`（低端机玻璃降级）**刻意未接**，`MotionTier` 已就绪但传 1f。
- 设置页其余 10 处返回钮仍是 M3（半迁移）。
