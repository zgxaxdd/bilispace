## 0. 一句话目标

把 BBSpace 的性能治理从"四个专项"扩到**全部页面与交互路径**：消掉 4 类**会在真机上真实发作**的缺陷（恢复路径不可达、trim 漏登记导致内存收不回、主线程做重活、列表重复 key 崩溃），把全站玻璃链纳进同一个帧守卫与预算体系，并把"守卫只管源码调用点、不管运行期实例数"这个系统性盲区补上——**全部验收在无设备条件下可判死**。

**不做**：不改任何用户可见的默认行为；不为了数字改视觉；不碰没有设备就无法验证的东西；不做功能开发（功能冻结令）。

## 3. 铁律

### 3.1 工程纪律（违反会造成难以发现的损坏）

1. **绝不用 PowerShell / python 改文件内容。** 历史上用 `Set-Content -Encoding UTF8` 把 `VideoPlayerPane.kt` 的中文写成乱码——**仍是合法 UTF-8、能编译、极难发现**；`FINDINGS` W25 记录这条已复发 5 次。一律用 `edit` / `write`；**临时改坏也一样**（W10）。
2. **pwsh 的 `cd` 不跨调用保持**；`[System.IO.File]::*` 的相对路径基准是进程 CWD，**一律绝对路径**。
3. 构建命令：
   ```powershell
   cd D:\111j\c\_ref\bbspace
   $env:GRADLE_USER_HOME="D:\env\gradle-home"; $env:JAVA_HOME="D:\env\jdk17"
   .\gradlew.bat :app:assembleDebug --console=plain
   .\gradlew.bat testDebugUnitTest --console=plain
   ```
4. **同一目录绝不并发跑两个 Gradle 构建**（W12）；连续构建撞 `classes.jar` 文件锁（W17）时先 `.\gradlew.bat --stop`。
5. **判"某能力不可用"前，把配置查找路径走一遍**（W2）：项目级 → `GRADLE_USER_HOME` → 环境变量 → `-P`。
6. **新文件写完必须核对"目录 == 包名"**（W8）。包名是 `com.naaammme.bbspace`（**三个 m 三个 a**）。

### 3.2 守卫与测试纪律（本文件最看重的一节）

7. **扫源码型守卫会被 Gradle 判 `UP-TO-DATE` / `FROM-CACHE` 静默跳过**（W5 / ST-26）。每次宣称"守卫会咬人"必须确认那一轮**真的执行了**：日志里是 `> Task :x:testDebugUnitTest` 而非 `UP-TO-DATE`。
8. **`--rerun` 只在命令行只有一个任务时生效**（W22）——多模块必须**逐个模块**单独调用。破坏性验证先看 `BUILD` 行、再看 XML 的 mtime、最后才读内容（W17）。
9. **每条守卫必须配一对正反例**（W21）：只写"应当抓不到"的断言，正则一失效它就永久成立。
10. **扫描锚点只认代码形态**，不认注释（W21/W20）：用 `^\s*\.drawBehind\s*\{` 这种形态匹配，不用 `contains("drawBehind")`。
11. **"某处必须调用 X"的守卫要匹配调用本身，不要匹配名字**（W20）——定义行也是一处匹配。用 `Regex("""(?m)^\s*名字\(\)\s*$""")`。
12. **棘轮上限的 actual 必须用本仓扫描器读**，不要另写脚本（W24：`countMatching` 统计的是**匹配行数**不是出现次数，实测差 12 处）。
13. **守卫的规则要精确到"缺陷本身"，不要按文件一刀切**（W18）——按文件写禁令的结局一定是"加豁免"，带豁免的守卫从此就是噪音。**本文件所有守卫建议均已遵守此条。**
14. **给扫描 helper 加 `require(!prefix.startsWith(" "))`**（W23）：前缀带缩进会静默失配，红得莫名其妙。
15. **JVM 单测跑的是桌面 JDK 的协议处理器**（W19）：断言写"结果属于哪一类受控失败"（异常类型），不要写"命中哪一行"。
16. **棘轮只许降**；要调大必须**连同上限一起改并写明理由**（`FrameBudgetLintTest` 的设计意图就是让这个动作显眼）。

### 3.3 判定纪律

17. **不许在没有设备时写任何帧率 / 内存 / 耗时数字**；定量位置一律写「待真机」+ 预期信号 + 取证命令。
18. **交接文档里的行号与数字必须自己复核再采信**（W4）。本轮已据此**推翻/修正了 6 条上游结论**，见 §4。
19. **无真机时 release 变体采不到诊断**（`BiliApplication.kt:51` `Logger.init(BuildConfig.DEBUG)`）→ 所有真机验证**一律在 debug 变体做**。
